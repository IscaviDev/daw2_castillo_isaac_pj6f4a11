# Order Management App

E-commerce web application used by the sales staff of **BuildPro Construction Supplies** to create and view customer orders.

Project PJ6 (Back-end with PHP) - DAW2, Escola del Clot, 2026-27.

## Folder structure

```
orderManagementApp/
├── application/
│   ├── client/        → JavaScript, HTML and CSS code (client side)
│   └── server/        → PHP code (server side)
├── orders/
│   └── orders.json    → all orders (created automatically with the first order)
└── users/
    └── users.json     → predefined application users (read only)
```
