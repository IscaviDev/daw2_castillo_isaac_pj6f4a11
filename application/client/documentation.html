BuildPro Order Manager

Description and documentation

About the application

BuildPro Order Manager is the e-commerce application used by the sales staff of BuildPro Construction Supplies, a European chain of construction material stores. It allows sales staff to register the orders placed by customers and to look them up later. Prices, VAT calculations and data storage are always handled by the server.

Product catalogue

Orders can only include the following four products (prices without VAT):

  • Grey cement CEM II/B-L 32.5 N, 25 kg bag
  • Double hollow brick, 24 x 11.5 x 8 cm
  • Plasterboard, 2500 x 1200 x 13 mm
  • White matt interior plastic paint, 15 L bucket

Access to the application

Click Log in and enter your user name and password. Both fields are mandatory. If the server cannot validate the user, an authentication error is shown and you are taken back to the start page.

Operations menu

After logging in, choose an operation from the drop-down menu and click Go to selected operation. The available operations are:

1. Create a new order

  1. Enter the order code (3 to 20 letters, numbers or hyphens, for example ORD-001). Each code can only be used once.
  2. Enter the customer's full name (first name and surname), postal address, email address and phone number.
  3. Tick the products the customer wants to buy. Ticking a product enables its quantity field; enter a whole number of units (at least 1).
  4. Click Send order. The server calculates the total price including 21% VAT, saves the order and the total is shown below the form.

If any data is missing or incorrect, a message explains what needs to be fixed and the order is not sent.

2. View orders

Choose one of these options from the orders view menu and click Go to selected view:

  • View all orders: shows a table with all the data of every saved order.
  • View one order: enter the code of an order and click Show order to see a table with all its data.

If no orders have been saved yet, or the orders file cannot be opened, an error page is shown. An error page is also shown when there is no order with the code you entered.
